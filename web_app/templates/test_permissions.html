🔧 How to Fix Camera Access Denied

            
            

                
Method 1: Browser Permissions (Easiest)

                
    
                    
  1. Look for a 🔒 lock icon or camera icon in the address bar
    2. 
                    
  2. Click it and select "Allow" for both Camera and Location
    3. 
                    
  3. Refresh this page and click the test buttons again
    4. 
                

            

            
            

                
Method 2: Windows Privacy Settings

                
    
                    
  1. Press Windows + I to open Settings
    2. 
                    
  2. Go to Privacy & Security → Camera
    3. 
                    
  3. Turn ON: "Camera access"
    4. 
                    
  4. Turn ON: "Let apps access your camera"
    5. 
                    
  5. Turn ON: "Let desktop apps access your camera"
    6. 
                    
  6. Do the same for Location section
    7. 
                    
  7. Restart your browser
    8. 
                

            

            
            

                
Method 3: Clear Browser Site Data

                
    
                    
  1. In browser address bar, click the 🔒 icon
    2. 
                    
  2. Click "Site settings" or "Permissions"
    3. 
                    
  3. Find Camera and Location, set both to "Allow"
    4. 
                    
  4. Or click "Reset permissions"
    5. 
                    
  5. Refresh and try again
    6. 
                

            

            
            

                
Method 4: Use External Browser

                
VS Code's Simple Browser has limited permissions. Try:

                
    
                    
  1. Open Chrome or Edge externally
    2. 
                    
  2. Navigate to: http://localhost:5000
    3. 
                    
  3. Grant permissions when prompted
    4.
